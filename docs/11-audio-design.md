# 音频设计与素材边界

## 目标

让战场具备“指令 → 反馈 → 环境 → 战斗”的听觉层次，同时保持网页端首屏轻量、浏览器自动播放限制可控，并且不打包原版游戏的受版权保护音频。

## 四层声音

1. **效果音（Effects）**：选择、移动、建造、排队、生产完成、开火、命中、爆炸、缺电警告。
2. **环境声（Ambient）**：低通风声、电力低频嗡鸣、采矿与卸矿提示。音量很低，不抢指令和战斗信息。
3. **音乐（Music）**：原创的短音符/低音循环。使用 Web Audio 调度，不下载大体积文件；后续可以替换成拥有授权的 OGG/MP3。
4. **语音（VO，预留）**：未来接入“收到 / 建造完成 / 资金不足”等短语音时，走同一个音频总线，不在状态层写浏览器对象。

## 实现约束

- `GameState` 只产生瞬态事件和可回放命令；Audio 层在渲染帧读取，不影响固定 tick 的确定性。
- 浏览器第一次 `pointerdown` 或 `keydown` 后才解锁 `AudioContext`，解锁失败不能阻塞游戏。
- Effects、Music、Ambient 分开走 GainNode，总音量再通过 Master Gain 统一控制。
- 所有音量写入 `localStorage`，刷新或读档不会突然恢复默认音量。
- 音效文件如果未来加入，必须使用原创或明确允许商业/再分发的素材，并记录来源与许可证。

## 事件映射

| 游戏状态变化 | 声音反馈 |
| --- | --- |
| 选择单位/建筑 | 短促确认音 |
| 移动、停止、建造放置 | 指令音 |
| 加入生产队列 | 队列确认音 |
| 单位生产完成 | 两段式完成提示 |
| 采矿 / 卸矿 | 低频机械提示 |
| 电力从正常变为不足 | 一次警报，不循环轰炸玩家 |
| 开火 / 命中 / 摧毁 | 分层武器、冲击、爆炸音 |

## 后续升级

- 为不同武器族增加独立波形与混响参数。
- 对远近目标增加简单音量衰减和左右声道声像。
- 给建筑和单位加入短语音包，区分己方、敌方和警报。
- 当浏览器允许时，将授权音乐切换为场景化曲目；合成循环作为离线和低带宽兜底。
